# INN-from-scratch-lab

> ⚠️ **Work in Progress** — This repository is actively under construction. Nothing here is finished or polished yet.

This repository documents my personal process of studying **Interpolating Neural Networks (INNs)** through paper notes and simplified Python experiments. The goal is to build understanding from the ground up — not to produce a production-ready implementation.

## What this repo is (and isn't)

**This repo IS:**
- A place to collect my paper notes and reading summaries
- A scratchpad for small, exploratory Python experiments
- A running record of my questions, confusions, and gradual understanding

**This repo is NOT:**
- A complete INN implementation
- A benchmark comparison framework
- A polished or production-ready codebase
