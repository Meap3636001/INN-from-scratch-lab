# INN-from-scratch-lab
A learning repository for studying Interpolating Neural Network (INNS) through notes and simplified Python experiments.

## About

This repository documents my process of studying **Interpolating Neural Networks (INNs)** through paper notes and simplified Python experiments.

The main reference is:

**Unifying machine learning and interpolation theory via interpolating neural networks**  
Nature Communications, 2025  
DOI: https://doi.org/10.1038/s41467-025-63790-8

## Project Status

This repository is currently in the early reading and planning stage.

The goal is **not** to fully reproduce the original paper at this stage. Instead, this project focuses on understanding the core ideas of INNs and gradually implementing small-scale experiments from scratch.

## Initial Goals

- Summarize the main idea of INNs in my own words.
- Compare INNs with FEM-style interpolation and standard neural networks.
- Implement a simple 1D interpolation demo.
- Implement a minimal 1D INN-style trainer.
- Compare a simple INN model with a small MLP on a toy regression problem.
